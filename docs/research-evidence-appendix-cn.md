# Chengdu Lens 研究与证据附录

## 1. Evidence Status

本项目公开材料仅供作品集所用。所有材料必须区分四类信息：

| 类型 | 可以如何使用 | 不可以如何使用 |
|---|---|---|
| 已验证二手事实 | 支持问题背景和设计约束 | 不能当作产品结果 |
| 研究假设 | 设计 Demo 场景和测试任务 | 不能写成用户访谈结论 |
| 模拟数据 | 验证交互、字段和状态机 | 不能说成实时评分或真实用户行为 |
| 待验证计划 | 展示下一步方法 | 不能说成已完成验证 |

文档不包含真实用户访谈样本，因此文档不使用虚构用户原话。

## 2. Research Questions

核心问题：

1. 国际游客在成都做城市发现时，是否更关注“适合我”和“为什么可信”，而不是更多推荐数量？
2. 将中国平台信号、国际游客信号和官方事实分层展示，是否能提高信任？
3. 用户是否愿意先收藏地点，再让 Agent 生成路线？
4. 局部重规划是否比重新生成整份攻略更符合真实旅行决策？
5. 国际游客的执行障碍主要来自语言、预约、支付、导航还是现场规则？

## 3. Scenario Framework

“国际游客”不是一个单一画像。场景定义基于任务和能力变量：

- 首次来中国还是熟悉中国旅行。
- 是否能使用中文 App。
- 是否能处理预约、支付、导航和现场沟通。
- 旅行主要动机：经典地标、城市生活、美食、文化、摄影、家庭、四川延伸。
- 明确限制：时间、饮食、预算、体力、同行者。

六个主场景：

| 场景 | 目标 | 主要风险 |
|---|---|---|
| 第一次来中国 | 看到成都代表性体验但不被复杂流程劝退 | 语言、支付、预约、信息过载 |
| 当代城市探索 | 找到独立空间、街区和视觉体验 | 推荐同质化、地点质量不稳定 |
| 川菜动机 | 体验成都食物但控制辣度和卫生风险 | 饮食限制、排队、菜单语言 |
| 文化考古 | 访问博物馆、遗址和历史空间 | 预约、讲解语言、游览时间 |
| 国际家庭 | 兼顾孩子、长辈、休息和安全 | 体力、卫生间、室内备选 |
| 四川延伸 | 从成都出发理解川西/阿坝/甘孜机会 | 距离、交通、安全、合规服务 |

次级压力测试包括国内首次游客、本地重新发现、摄影、购物、博物馆深度、行动能力有限和多人同行冲突。

## 4. Candidate Place Strategy

候选地点不是“热门景点列表”，而是用于测试产品判断的样本池。首版 Demo 应选 6 到 8 个地点，覆盖：

- 经典但需要语境的地点
- 本地生活和街区体验
- 美食与非辣选择
- 博物馆或文化空间
- 适合拍摄的城市空间
- 雨天或低体力备选

地点纳入标准：

- 能支撑至少一个明确用户场景。
- 有可链接来源或官方信息入口。
- 可说明适合谁和不适合谁。
- 能被地图和时间约束验证。
- 对国际游客的可执行风险可描述。

暂不纳入：

- 只能靠平台评论支撑、无稳定来源的地点。
- 涉及安全、合规或供给责任但无法验证的服务。
- 需要复杂交易闭环的包车、组团、导游撮合。

## 5. Source Policy

可以使用的来源类型：

- 官方网站、景区页面、博物馆页面和政府文旅信息。
- 地图链接和公开 POI 信息入口。
- OTA 或点评平台的地点链接。
- 国际旅游讨论、攻略和社区内容的链接级引用。
- 手动整理的编辑备注。

不可使用：

- 复制第三方平台评论全文。
- 复制用户名、头像、个人资料和未经授权评分。
- 把小红书、抖音、点评等平台内容当作可自由训练或抓取的数据。
- 把平台热度当作事实质量。

作品集 Demo 可以展示“来源链接”和“来源类型”，不展示未经授权的评论内容。

## 6. Validation Plan

如果继续推进，建议按低成本顺序验证：

| 阶段 | 方法 | 样本 | 成功标准 |
|---|---|---|---|
| Desk validation | 来源登记和地点字段补齐 | 20 个地点 | 关键字段可追溯 |
| Usability test | 远程可用性测试 | 5 位国际旅行经验用户 | 2 分钟内完成收藏和路线 |
| Concept interview | 半结构访谈 | 6 到 8 位潜在用户 | 能复述产品价值和信任点 |
| Agent eval | 离线任务集 | 30 个任务 | 硬约束错误率低于设定阈值 |
| Market test | 公开 Demo 或 waitlist | 小流量 | 收藏率、路线生成率、来源点击率达标 |

在完成这些验证前，不应声称产品已有用户需求验证或商业 traction。

## 7. Risks

- 数据授权风险：第三方平台内容只能链接，不应复制。
- 实时性风险：营业、价格、预约和天气必须标记更新时间。
- 文化误读风险：不能把地方文化简化成拍照标签。
- 国际化风险：英文可读不等于现场可执行。
- Agent 风险：模型生成流畅文案可能掩盖事实缺失。
