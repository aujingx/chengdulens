# Chengdu Lens · 演示验收

[产品规格](product-spec-cn.md)定义完整需求，[产品蓝图](product-roadmap-cn.md)说明未来设想；本页仅覆盖已实现的演示。

## 主线

首页不预设任何行程。用户先选「随便走走」或「定制行程」，说出或点选自己的时间、出发地、今晚和明天，再决定自己挑还是交给 AI。

| 操作 | 应看到的结果 |
| --- | --- |
| 打开首页 | 首屏展示三种用法；没有预设时长、出发地或九寨沟行程 |
| 随性漫游：选「文殊院」和一种心情 | 2–3 站、约 3 小时内的路线；「换一条」可更换；下雨时只给室内地点 |
| 点「以此为起点，安排今天剩下的」 | 进入定制行程，带入出发地和站点，其余项仍标「待选」 |
| 定制行程：什么都不填 | 两个开始按钮不可用，提示还差哪几项 |
| 输入「一整天，从天府广场出发，已经订好酒店，明天还没想好」并托管 | 只有「去哪逛 → 晚餐 → 总览」，没有酒店和九寨沟 |
| 在总览点「明天去九寨沟」 | 新增明天步骤：高铁、接驳、住宿、晚餐各三选一；今天的选择不变；可「明天不去了」移除 |
| 打开今天或明天的「查看预订与官方核对」 | 只出现当天目的地的选项 |
| 获取模拟报价 → 确认 → 模拟付款成功但订房失败 → 退款 | 显示已模拟退款、预订取消；不扣款、不创建真实订单 |
| 输入提到乐山等未收录地点 | 明确提示未收录，不自动换成九寨沟 |
| 切换英文；在窄屏走同一流程 | 入口、操作、状态与结果在中英文都可用 |

## 范围
- 9 个精选成都地点，带来源、周边推荐和交通说明；周边线路仅九寨沟。
- 天气来自 Open-Meteo 实时数据，可手动更正；路线时长为估算。
- 官方链接供自行核实；模拟价格不代表市场价。点击流程验收不等于用户研究。
